# Carpeta de sonidos

Pon aquí tu música (`.mp3`) y tus efectos de sonido (`.wav` o `.mp3`). Después
asocia cada archivo a un "id" en `config/audio.json`.

## ¿No tienes sonidos todavía?

No hay problema: si un archivo no existe, simplemente no suena y el juego
funciona igual. Añade los archivos cuando quieras.

## Sonidos que usa el juego de ejemplo

| Archivo        | Tipo    | Cuándo suena                         |
|----------------|---------|--------------------------------------|
| `intro.mp3`    | Música  | Pantalla de título                   |
| `pueblo.mp3`   | Música  | En el escenario del pueblo           |
| `bosque.mp3`   | Música  | En el escenario del bosque           |
| `accion.mp3`   | Música  | Durante los mini-juegos de acción    |
| `click.wav`    | Efecto  | Al pulsar botones / acciones         |
| `toque.wav`    | Efecto  | Al atrapar una estrella              |
| `exito.wav`    | Efecto  | Al acertar / ganar                   |
| `fallo.wav`    | Efecto  | Al fallar / camino bloqueado         |
| `golpe.wav`    | Efecto  | Al chocar con una roca               |
| `puerta.wav`   | Efecto  | Al cambiar de escenario              |

Consejo: para música, busca pistas "loop" (que se repiten sin notarse). Usa
sonidos con licencia libre (por ejemplo de OpenGameArt o Freesound) y respeta
sus condiciones de uso.
